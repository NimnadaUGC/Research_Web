Proposed Approach: Three Pillars

A comprehensive framework combining adaptive prompting, ethical safeguards, and human-in-the-loop hybrid agents

The Three-Pillar Framework

Our methodology is built on three interconnected pillars, each addressing a specific research question. Together, they form a cohesive, human-centered approach to AI-enhanced Business Analysis.

1

Adaptive Prompt Engineering Pillar 1

Objective: Reduce ambiguity in requirements through iterative, context-aware prompting.

  • Stakeholder input → Initial requirement sketch
  • Ambiguity detection → Identify vague terms, missing constraints
  • Clarification loop → AI generates targeted questions
  • Refinement → Updated user stories, SRS with clarity scores
2

Ethical Prompting & Bias Reduction Pillar 2

Objective: Improve transparency and reduce fairness risks in AI-generated artifacts.

  • Bias-sensitive language detection → Flag loaded terms, hidden assumptions
  • Stakeholder fairness prompts → Ensure all voices are considered
  • Transparency notes → Explicit assumptions, trade-offs, dependencies
  • Traceability → Link decisions back to source stakeholders
3

Hybrid AI Agents (Human-in-the-Loop) Pillar 3

Objective: Support BA workflows while maintaining human oversight and decision-making power.

  • Modular agents → Elicitation Assistant, Ethics Checker, Documentation Generator
  • Human feedback loop → BA reviews, approves, or revises AI output
  • Traceability → Audit trail of AI suggestions and human decisions
  • Reproducibility → Open-source toolkit for local SME adoption

Workflow Integration

End-to-End Artifact Flow

Stakeholder Input → Elicitation Agent (clarification) → Ethics Checker (bias audit) → Documentation Generator (final output) → Human Review (approval) → Refined BA Artifact

Elicitation Assistant

  • Accepts unstructured stakeholder input (verbal notes, rough sketches)
  • Generates clarification questions using iterative prompts
  • Synthesizes responses into user stories (INVEST framework) and acceptance criteria
  • Provides clarity score based on rubric (completeness, specificity, testability)

Ethics Checker

  • Audits generated artifacts for bias-sensitive language
  • Flags assumptions, hidden dependencies, and stakeholder representation gaps
  • Generates transparency notes (what was assumed, why, alternatives considered)
  • Provides bias flag counts and severity ratings

Documentation Generator

  • Synthesizes refined stories and acceptance criteria into SRS format
  • Includes traceability matrix (requirement → stakeholder source)
  • Generates technical and functional constraints documentation
  • Produces one-page executive summary for quick alignment checks

Human Review Loop

  • BA reviews AI output, approves or requests revisions
  • Audit trail logs all changes and human decisions
  • Stakeholder feedback incorporated via feedback loop to Elicitation Agent
  • Final artifact ready for developer handoff

Evaluation Approach

Mixed-methods evaluation combining quantitative metrics and qualitative insights from SME participants:

Quantitative Metrics

  • Clarity Score: 1–5 rubric (completeness, specificity, testability)
  • Bias Flags Count: # of detected risks per artifact
  • Time to Completion: Baseline vs. AI-assisted workflow
  • Defect Rate Post-Dev: Rework incidents due to vague/incorrect specs

Qualitative Evidence

  • BA Interviews: Usability, trust, cognitive load, confidence
  • Developer Feedback: Spec clarity, completeness, handover friction
  • Stakeholder Surveys: Fairness perception, representation, trust
  • Thematic Analysis: Emergent patterns in adoption barriers/enablers

A/B Trial Design

Matched-task studies across 3 SMEs comparing manual BA workflow vs. AI-augmented workflow using the same artifacts and metrics.

Success Criteria

  • 20–40% improvement in clarity scores
  • 15–30% bias flag reduction after ethics checks
  • 30–50% time savings in specification phase
  • Positive BA feedback on trust & usability

A lean, open-source toolkit built with Python, Streamlit, and LLM APIs:

Phase 1: Elicitation Assistant

Tools: Streamlit UI + OpenAI/LLaMA call

Input: Unstructured stakeholder notes

Output: User stories (INVEST), acceptance criteria, clarity score

Months 1–2

Phase 2: Ethics Checker

Tools: Bias-lint library (Python) + custom rubric

Input: Generated stories, acceptance criteria

Output: Bias flag list, transparency notes

Months 2–3

Phase 3: Documentation Generator

Tools: Jinja2 templates + Markdown export

Input: Refined stories, bias-checked artifacts

Output: SRS PDF, traceability matrix, summary docs

Months 3–4

Phase 4: Integration & Testing

Tools: GitHub Actions, pytest, user acceptance testing

Input: Real SME pilot data

Output: Refined toolkit, documentation, deployment guide
